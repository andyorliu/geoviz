# Dashboard Evaluation Questions

## Post-Task Evaluation Survey

After completing the analytical tasks using the dashboard, please answer the following questions:

1. **Confidence in Insights**: On a scale of 1-5, how confident do you feel that the insights you generated from the dashboard (e.g., identifying high-crime areas, comparing temporal patterns, finding multi-dimensional hotspots) are accurate and reliable? Please explain any concerns or uncertainties you have.

2. **Dashboard Navigation**: How easy or difficult was it to find and use the different features needed to complete the tasks (filters, map views, charts, statistical panels)? Were there any features you expected to find but couldn't locate, or any that were confusing to use?

3. **Multi-Dimensional Filtering**: When combining multiple filters (crime type + time + day + season) for Task 4, how intuitive was the process? Did you encounter any confusion about how filters interact with each other or how to interpret the results when multiple filters are applied simultaneously?

4. **Visualization Clarity**: How clear and interpretable were the visualizations (heatmaps, time series charts, area comparisons)? Were there any charts or maps that were difficult to understand, or any that you felt were particularly helpful for generating insights?

5. **Overall Usability**: What was your overall experience using the dashboard? Please describe any specific usability issues you encountered (e.g., slow loading, unclear labels, unexpected behavior) or aspects that worked particularly well.
